# WP-2_PC-Mortality-Prediction

This analysis code supports Work Package 2 of SCAN 2030 – Prostate Cancer, utilizing Electronic Medical Records from the Hong Kong Hospital Authority. While the code itself cannot be directly shared, researchers can access the relevant data by applying through the HA Data Sharing Portal: https://www3.ha.org.hk/data/Provision/ApplicationProcedure.

The study is available through the [SCAN 2030 project website](https://scan2030.hku.hk/en/publications/predicting-disease-progression-and-mortality-in-prostate-cancer-using-real-world-data-driven-time-inhomogeneous-markov-models), or through [iScience](https://www.cell.com/iscience/fulltext/S2589-0042(26)02915-9).
